# 判定と利用者への質問

正本の選定は[正本候補の選定規約](canonical-selection.md)を先に適用する。

`dedupe.mode` が `auto`（既定）の場合は、
[自律正本化モード](autonomous-canonicalization.md)がこの資料の質問待ち規則に優先する。

- **確信できる場合**（同じ主張を別の言葉で書いているだけと判断できる）→
  完全一致の重複と同じ手順で是正する。本来の置き場所（より詳細・下位の
  文書）を決め、他方はポインタ1行に置換する。移動とポインタ化のみとし、
  要約・言い換えによる内容変更は行わない
  （文書構造是正スキルの「不変条件」）
- **正本化か重複許容かで迷う場合**→ 正本性を高めることを判断基準にする。
  文書ごとの役割、読者、詳細度を確認し、内容を変えずに正本とポインタを
  定められるなら、正本化して重複を解消する。重複を残す選択を自分だけで
  決めたり、`allow-duplicate` マーカーを自分で追加したりしない
- **確信が持てない場合**（意味が重なるのは一部だけ、対象読者・文脈が
  異なる、片方が要約でもう片方が手順の詳細、など）→ その場で断定して
  統合せず、作業を止めて利用者に質問する。質問には、比較した箇所へのリンク、
  重なって見える内容、統合をためらう差異、正本化する場合と重複を残す場合の
  影響を含める。回答があるまで候補を是正済みにせず、保守報告へ統合しない
- **意図して重複させるべき場合**（免責文言・定型の注意書きなど）→
  [duplicate-handling.md「意図した重複の許可」](duplicate-handling.md#意図した重複の許可)
  の `allow-duplicate` マーカーを使う。ただし、利用者が重複を意図して
  残すと明示的に回答した場合に限る。統合の対象からも外す
