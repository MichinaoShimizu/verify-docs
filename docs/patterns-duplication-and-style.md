# 重複・文体のパターン

- **同一理由の重複説明**: 同じ理由を複数回言い換えて説明している状態
- **強調の重ね置き**: 強調のための太字・繰り返しが、説明の直後にも
  重ねて置かれている状態
- **重複例示**: 同じ論点を示す例示が複数列挙されていて1つで足りる状態
- **同義語の重ね書き**: 漢語と和語で同じ意味の動詞を並べているだけの
  表現（同義語2語を「・」で並べる形）
  （例:「検討・考慮する」→「検討する」）
- **括弧内言い換え注釈**: 括弧内の注釈が本文の単純な言い換えで、本文
  だけで意味が通じる状態（例:「〜秒（つまり〜秒間）」→「〜秒」）
- **重言**: 一方の語がもう一方の意味を既に含んでいるのに両方を続けて
  使っている複合表現（1つの複合語の中に意味の重複が埋め込まれている点で
  「同義語の重ね書き」と異なる）。例:「まず最初に」→「まず」、「今の現状」→
  「現状」、「違和感を感じる」→「違和感がある」
- **文体の混在**: 同一文書内でです・ます調とだ・である調が混在している
  箇所。少数派の文を、文書内で多数派の文体に合わせて変換する。読者向けの
  文体は文書の方針であるため、です・ます調が多数派の文書をだ・である調へ
  変えない。箇条書きの項目、表のセル、コードのコメント、引用の常体や体言止めは
  混在とみなさない。だ・である調への変換例:
  「〜します」→「〜する」、「〜です」→「〜だ」、
  「〜ではありません」→「〜ではない」、「〜でした」→「〜だった」、
  「〜ません」→「〜ない」

## 文書単位の冗長性

同一文書内で、既存の記述と同じ役割しか持たず、固有の条件・例外・判断基準・
対象読者を追加しない部分は削除候補である。

- **同役割の節の結合**: 隣接または近接する節が同じ目的・前提・手順を扱う
  箇所。各節にだけある条件・例外・判断基準・対象読者と手順の順序を統合先へ
  保てる場合に、一つの節にする。削除または変更する見出しへの断片リンクは
  統合先へ付け替える
- **重複した導入説明**: 目的・対象・前提を別の節で繰り返している箇所。役割が
  異なる説明は残す
- **参照だけの見出し**: 固有の手順や条件を持たず、既出の文書へのリンクだけを
  繰り返す節。削除前に、その見出しを指す断片リンクを正本の見出しへ付け替える
- **旧形式の例**: 現行の手順・表・規則が同じ内容を示しており、旧例に固有情報が
  ない箇所
- **重複する参照案内**: 同じ正本へのリンクを、次の行動を変えずに複数回案内する
  箇所。最初の案内または実行時点の案内を残す

文書間の作業と、固有情報を保てるか判断できない候補の扱いは、`tighten-docs` の
`SKILL.md` の「不変条件」と「2. 冗長表現削減」に従う。
