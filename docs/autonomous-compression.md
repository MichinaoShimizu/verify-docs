# 自律圧縮モード

`tighten-docs` は `verify-docs.config.json` の `tighten.mode` を読む。`safe` は意味保持モード、
`auto` は既定の自律圧縮モードであり、設定がなければ `auto` とする。利用者またはリポジトリが
`safe` を明示した場合は、意味保持モードで実行する。対象・目標・禁止事項が指定されている場合は、
それらを優先する。

## 意味保持モード

意味、対象読者、条件、手順の順序、免責文言を保てると確信できない候補は変更せず、
利用者に質問する。質問には候補箇所へのリンク、削減案、失われるおそれがある内容、
変更する場合と残す場合の影響を含める。回答があるまで候補を是正済みにせず、保守報告へ
統合しない。

## 自律圧縮モード

多少の意味変更リスクがある削除・結合・言い換えも、ファイルサイズを減らすために実施する。
この不確実性を理由に利用者の回答待ちで停止せず、対象内の候補を処理して圧縮、検査、記録まで
完走する。候補を無回答の `回答待ち` として残さない。

ただし、事実を捏造しない。リンク・断片リンクを壊さず、Markdownとしての成立を保ち、文書間の
内容移動・正本化には広げない。法的・安全上の注意、契約上の義務、明示された数値・コマンド・
設定値は、削減が必要でも削除・変更しない。これらを守ったまま圧縮できない箇所は残し、未完了
にはせず理由を記録する。

一時作業記録と保守報告に `実行モード: 自律圧縮`、変更箇所、残したリスク、変更しなかった
保護対象、最終検査結果を記録する。対象内の候補を処理済みまたは保護対象として記録し、
`node scripts/document-structure-verifier.mjs` が「文書構造: すべて通過」で終われば完了とする。

既定モードとの圧縮率や必須事実の欠落を比べる場合は、同じ入力スナップショットから
[モード比較](mode-comparison.md)を実施する。
