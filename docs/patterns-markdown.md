# Markdown表現のパターン

- **連続空行の冗長化**: 2行以上連続する空行。Markdown上は1行の空行と
  同じ意味になる
- **強調記法の二重掛け**: 太字と斜体を同じ語句に重ねて使っている箇所。
  片方の記法だけで強調は伝わる（例: `**_強調_**` → `**強調**`）
- **リンクテキストのURL再掲**: リンクテキストがURL文字列そのものの
  繰り返しになっている箇所（例: `[https://example.com](https://example.com)`
  → `<https://example.com>`）
- **表形式の記号オーバーヘッド**: 各行が単純な対応関係（用語→定義の
  ような1対1）に過ぎないのに表（ヘッダー区切り行・各行の`|`）を
  使っている箇所。箇条書き（`- **用語**: 定義`）で同じ対応関係を、
  区切り記号を増やさずに表現できる
- **装飾目的の絵文字**: 見出し・箇条書きの先頭にある、削っても構造や
  意味の認識に影響しない絵文字（例:「## 🚀 デプロイ手順」→
  「## デプロイ手順」）
- **表の桁揃えの空白**: 列幅を揃えるためだけに、表のセル内へ詰めた空白や
  区切り行の連続ハイフン。表示結果は変わらないため、各セルの前後1文字と区切り行の
  `| --- |` まで詰められる。文書の規模によっては最も削減量が大きい。対象リポジトリが
  Prettier などの整形ツールで表を桁揃えしている場合は、整形で元に戻るため変更しない
