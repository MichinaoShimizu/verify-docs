# 語句・文法のパターン

- **見出し直後の言い換え文**: 見出しをそのまま言い換えているだけで情報を
  追加していない一文が、見出し直後に置かれている状態
- **見出しの名詞句化**: 見出しが「〜する」で終わる動詞句のままになっている状態。
  名詞句にして短くなる場合だけ言い換える。省略できる助詞（の・を等）は省略して
  複合名詞にする（例:「重複を削る」→「重複削減」、「サイズの変化」→
  「サイズ変化」）。「〜にアクセスする」→「〜へのアクセス」のように長くなる場合は変えない
- **冗長接続表現**: 無くても意味が通じる接続表現（例:「〜だからである」）
- **枕詞**: 削っても文意が変わらない前置き（例:「なお、」「ちなみに」
  「基本的には」）
- **冗長な可能表現**: 回りくどい可能表現。する動詞は「〜できる」、それ以外の動詞は
  可能形にする（例:「設定することができる」→「設定できる」、「渡すことができる」→「渡せる」、
  「〜することもできる」→「〜もできる」）。「知れる」のように可能形が文書の文体に合わない場合、
  「〜を指定することもできる」→「〜を指定もできる」のように不自然になる場合、可能形が読点の前で
  命令形と同じ形になる場合（「持て、」）は変えない
- **形式名詞の多用**: 「〜という」を挟むだけで名詞化している表現
  （例:「〜するということ」→対応する名詞句）
- **不要な受け身**: 主語が明確なのに使われている受け身表現
  （例:「〜が行われる」→「〜する」）
- **冗長な条件節**: 分岐が実質1つしかないのに毎回明示している条件節
  （例:「〜の場合には」）
- **「〜を行う」表現**: サ変名詞に「〜を行う」を続けているだけの表現
  （例:「テストを行う」→「テストする」）。名詞に修飾語が付く場合（「特別な処理を行う」）は変えない。
  同じ置換を多数の文書へ機械的に適用するときは、一部の該当箇所を原文で読んで不自然な結果がないか確かめる
- **話題化マーカー**: 外しても文意が変わらない話題化の表現
  （例:「〜については、」）
- **二重否定**: 意味を変えずに肯定形へ言い換えられる否定の否定
  （例:「〜ないわけではない」→「〜である」）
- **語句の連続誤字**: 誤字起因で同一語句が連続しているだけの箇所
  （例:「〜のの」「〜するする」）
- **概数の二重化**: 概数表現を二重に示しているだけの箇所
  （例:「約100個程度」→「約100個」）
- **冗長な言い回し**: 上のどの型にも当たらず、より短い語に置き換えても意味が変わらない表現
  （例:「〜を使用して」→「〜で」、「〜することによって」→「〜して」）。作業記録ではこの名前で記録する

## 英語文書での相当表現

上のパターンは日本語の例で示している。英語文書では、同じ役割の表現を対象にする。

- **枕詞・冗長接続**: `Note that`、`Basically,`、`simply`、`just`、
  `The reason … is because` → `because`
- **冗長な可能表現・形式名詞**: `is able to` → `can`、`the fact that` → `that`
- **「〜を行う」表現**: `perform a test` → `test`、`make a decision` → `decide`
- **冗長な条件節**: `in the case that` → `if`、`in order to` → `to`
