# 文書簡潔化スキル

| 項目 | 値 |
| --- | --- |
| 和名 | 文書簡潔化スキル |
| 英名 | DocumentTighteningSkill |
| ファイル名 | `SKILL.md` |
| リポジトリ内パス | `.agents/skills/tighten-docs/SKILL.md` |
| 配布先パス | `.agents/skills/tighten-docs/SKILL.md` |
| スキルID | `tighten-docs` |

## 適用範囲

意味を変えない簡潔化・冗長表現の削減を依頼された場合に使う。通常の文書作成・
小規模な文書修正・一般的なレビューでは使わない。

## 目的

文書構造是正スキルの検査はサイズ超過という結果のみを見る。冗長かどうかの判定・
削り方は検査対象外であり、本スキルが人・エージェントの判断で埋める。

## 実行モード

`tighten.mode` は `safe`（意味保持）か `auto`（既定の自律圧縮）。
設定がなければ `auto`。利用者またはリポジトリが `safe` を明示した場合だけ意味保持モードに戻す。
境界・保護対象・記録方法は
[自律圧縮モード](../../../docs/autonomous-compression.md)を参照する。

## 前提条件

対象リポジトリに文書構造是正スキル一式（`scripts/document-structure-verifier.mjs` と
`.agents/skills/verify-docs/`）が導入済みであること。検査対象・[保守報告](../../../docs/work-records-and-report.md#保守報告)規約は流用する。

## 不変条件

意味保持モードでは意味を変えない。数値・条件・手順の順序・免責文言は一字一句変更しない。
判断基準は「削っても次に何をすべきか・何が言いたいかが変わらないか」。
同一文書内の節は、統合後に各節の固有の条件・例外・判断基準・対象読者と
必要な手順の順序を全て保てる場合に限り、削除または結合できる。文書の分割、
文書間での正本化・内容移動・重複解消は
文書構造是正スキル・文書重複解消スキルの担当であり、本スキルの
対象外。

## 実施手順

### 1. 作業記録の作成

作り方は[作業記録と保守報告](../../../docs/work-records-and-report.md)を参照する。

一時作業記録に載せた対象文書は、共通抽出コマンドで段落の見出し階層・元位置・
本文・バイト数を一覧化し、確認する箇所を整理する。

```bash
node scripts/document-structure-extractor.mjs --root=. README.md docs/guide.md
```

対象が多い場合は、一時作業記録に列挙したパスを複数指定する。`bytes` はMarkdown記法を含む
元ソース範囲のサイズであり、抽出結果は候補の棚卸しに限る。必ず原文と「不変条件」を確認する。
`headings` の `bytes` と `paragraphCount` は子見出し以下を含むため、親子の値を合算しない。

### 2. 冗長表現削減

典型パターンの一覧で該当パターンの有無を1件ずつ確認する。
[語句・文法](../../../docs/patterns-wording.md)、
[重複・文体](../../../docs/patterns-duplication-and-style.md)、
[Markdown表現](../../../docs/patterns-markdown.md) を参照する。

導入説明・参照案内・例を削る場合は、同一文書の既存記述に対して固有の条件・
例外・判断基準・対象読者を追加していないことを確認する。同じ役割の節を結合
する場合は、各節にだけある情報を統合先へ残し、必要な手順の順序を変えない。
見出しを削除・変更する場合は、その見出しを指す断片リンクを統合先または残す
見出しへ付け替えた上で再検査する。文書間で正本を決める、内容を移す作業は
文書重複解消スキルに切り分ける。

意味保持モードでは、意味、対象読者、条件、手順の順序、免責文言を保てると確信できない候補を
変更せず、利用者へ質問する。質問と保守報告の扱いは[自律圧縮モード](../../../docs/autonomous-compression.md)
の意味保持モードを参照する。自律圧縮モードでは、同資料の記録規則に従い、質問待ちで停止しない。

### 3. サイズ変化記録

[作業記録と保守報告「サイズ変更の記録」](../../../docs/work-records-and-report.md#サイズ変更の記録)の様式（開始時点・最終サイズ・削減バイト数・開始時点からの削減率）に従う。

### 4. 是正後再検査

```bash
node scripts/document-structure-verifier.mjs
```

書き換えに伴うリンク切れ・断片リンク切れが発生していないか確認する。

## 完了基準

以下を全て満たした時点で完了とする。

- 一時作業記録の全項目にチェックが入っている
- [自律圧縮モード](../../../docs/autonomous-compression.md)のモード別完了条件を満たしている
- `node scripts/document-structure-verifier.mjs` が「文書構造: すべて通過」で終わっている
- 自分の一時作業記録に `### 最終検査結果` を記載して保守報告へ統合し、作業完了を
  報告する際は[保守報告](../../../docs/work-records-and-report.md#保守報告)のパスと実行結果を人に伝える

## 制約と対象外

- **文章の巧拙・語彙選択の良し悪しの評価。** 主観的な判断には踏み込まず、
  「意味を変えずに削れるか」のみを判断する
- **文書の分割、文書間の正本化・内容移動・重複解消。**
  文書構造是正スキル・文書重複解消スキルの担当。同一文書内の節削除・節結合は除く
- **意味を変える書き換え。** 意味保持モードでは、要約・言い換えで内容が変わるものは
  文書構造是正スキルの「不変条件」に反する。自律圧縮モードでは
  [自律圧縮モード](../../../docs/autonomous-compression.md)の保護対象以外に限り扱う
